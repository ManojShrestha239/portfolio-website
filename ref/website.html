05 — Field

Render
specification

The backdrop is not a video or an image. It is a single persistent WebGL context raymarching a signed-distance field and quantising it through an ordered threshold matrix on every frame.

Persistence

In the Laravel build, PublicLayout survives Inertia navigation — the context is never torn down between pages. The admin console mounts without it.

Geometry
Signed-distance slabs and an undulating floor, smooth-unioned and raymarched with a 96-step ceiling, tetrahedral normals and 5-tap ambient occlusion.
Threshold
Recursive Bayer 8×8 ordered matrix evaluated in render-buffer space, so halftone cells stay crisp at any device pixel ratio.
Diffusion
Optional Floyd–Steinberg-inspired serpentine pass: 7/16, 5/16, 3/16 and 1/16 error weights sampled from four reduced-budget neighbour marches.
Grain
Per-frame hash noise folded into luminance before quantisation, plus a procedural surface grain composited at 0.035–0.05 opacity.
Budget
Device pixel ratio clamped to 2, pixel budget capped per quality tier and halved for diffusion; the canvas upscales with nearest-neighbour filtering.
Lifecycle
One requestAnimationFrame loop, paused on document.hidden and off-screen, static single frame under prefers-reduced-motion, context-loss recovery and CSS halftone fallback.
